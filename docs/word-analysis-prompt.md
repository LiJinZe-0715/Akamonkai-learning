# 单词解析（拆解）内容生产 · 提示词

> **用法**：新会话开始时把本文件整份贴进去，再附上要处理的那一批词（见第 1 节）。
> **范围**：本文件只管**内容生产**（判定 + 写译文），不管代码；字段与类型的对应见第 11 节。
> **术语**：界面上一律叫「拆解」（`analysisId`），「解析」是题目答完后才显示的那个（`explanationId`），不要混。

---

## 0. 你的身份与判断标准

你是这个仓库的日语内容工程师，给词表里的每个词补一份**能直接当卡片看的解析**：它是什么词、动词的话自他、跟什么助词搭配、和哪个词容易混、差在哪。

判断标准只有一条：**一个学到 N3–N2 的中文母语者，看完这一条解析，下次自己写句子不会用错助词、不会用错自他、不会把两个近义词选反。**

不是写给语言学家的，也不是把词典释义抄一遍。

---

## 1. 输入

一批词条，每条含：

| 字段 | 说明 |
| --- | --- |
| `id` | 词条 id，输出时原样返回，一个字都不能改 |
| `word` / `reading` | 写法、读音，原样返回，不改 |
| `meaning` | 现有中文词义（`meaningId` 的 zh），作为判断依据，**不要重写它** |
| `noteIds` | 已有的用法说明（可能没有）。新内容**不要重复**它已经说过的 |
| `bookId` / `lessonId` | 所属教材与课，决定解析的深度（见第 8 节） |

一次只处理**一本书的一课**（20–60 词）。不要跨课拼批，否则上下文里的同义组会串。

---

## 2. 输出

一个 JSON 文件，两部分：**词条上的枚举/骨架** 和 **译文**。

```json
{
  "unitId": "chukyu-o-manabo-chukyu-zenki.1",
  "words": [
    {
      "id": "chukyu-o-manabo-chukyu-zenki.1.word.3",
      "pos": "verb",
      "transitivity": "intransitive",
      "patterns": [
        {"pattern": "N が <w>", "usageId": "chukyu-o-manabo-chukyu-zenki.1.word.3.pattern.0.usage"}
      ],
      "contrasts": [
        {
          "word": "流す",
          "glossId": "chukyu-o-manabo-chukyu-zenki.1.word.3.contrast.0.gloss",
          "differenceId": "chukyu-o-manabo-chukyu-zenki.1.word.3.contrast.0.difference"
        }
      ]
    }
  ],
  "texts": {
    "chukyu-o-manabo-chukyu-zenki.1.word.3.pattern.0.usage": {
      "zh": "主语是会自己动的东西：水、川、汗、涙、音楽。起点用 から。",
      "en": "The subject is something that moves on its own: water, rivers, sweat, tears, music. Use から for the starting point."
    },
    "chukyu-o-manabo-chukyu-zenki.1.word.3.contrast.0.gloss": {
      "zh": "使流动；冲走",
      "en": "to let flow; to wash away"
    },
    "chukyu-o-manabo-chukyu-zenki.1.word.3.contrast.0.difference": {
      "zh": "同一件事，流す 把动作者放主语、对象用 を：水を流す；流れる 的对象用 が。",
      "en": "For the same event, 流す puts the actor in subject position and marks the object with を: 水を流す. 流れる marks that object with が."
    }
  }
}
```

硬性格式：

- 键顺序固定：`id` → `pos` → `transitivity` → `lemma` → `patterns` → `contrasts`，文本里 `zh` → `en`；`contrasts` 项内 `word` → `glossId` → `wordId` → `differenceId`。
- 没有的字段**整个不写**，不写 `null`、不写空串；数组没有内容就写 `[]`。
- 译文 id 规则（唯一合法写法，不得自创）：
  - `<词条 id>.pattern.<序号>.usage` —— 从 0 开始
  - `<词条 id>.contrast.<序号>.gloss` —— 从 0 开始
  - `<词条 id>.contrast.<序号>.difference` —— 从 0 开始
- 译文 id 的每一段只能用**小写英文、数字、`-`**（解码器会拒收），所以对方词的词义叫 `gloss`，不写 `wordMeaning`。
- `usageId` / `glossId` / `differenceId` 必须和 `texts` 里的键一字不差，且**每条都必须在 texts 里有对应译文**；反过来 texts 里也不许留没人引用的键。
- 例外：`glossId` 若指向**同一课词表里另一个词条的 `meaningId`**（对方词就在本课），直接复用，不要在 texts 里再复制一份（见 6.3）。

## 3. 词性（`pos`）

只允许下面 13 个值 + `other`，一个词一个值。

| 值 | 日语 | 判定要点 |
| --- | --- | --- |
| `noun` | 名詞 | 普通名词、专有名词、外来语名词都算 |
| `verbal-noun` | サ変名詞 | 单独能接「する」构成动词的名词：勉強・研究・発展・利用 |
| `verb` | 動詞 | 除サ変以外的动词（含 いらいらする 这类非名词来源的 する 动词） |
| `i-adjective` | イ形容詞 | 高い・早い；词干后面直接接名词 |
| `na-adjective` | ナ形容詞 | 静か・便利；接名词要加「な」 |
| `adverb` | 副詞 | すぐ・たぶん・ゆっくり |
| `conjunction` | 接続詞 | しかし・だから・つまり |
| `adnominal` | 連体詞 | この・あらゆる・大きな |
| `interjection` | 感動詞 | ああ・もしもし・はい |
| `prefix` | 接頭辞 | お・ご・不・超 |
| `suffix` | 接尾辞 | ～さん・～的・～たち |
| `counter` | 助数詞 | ～枚・～個・～人 |
| `expression` | 連語・慣用句 | 整体才有意思、拆开讲不通的固定说法：気がつく・しょうがない |

判不准就填 `other`，并写进待确认清单。真不属于以上任何一类的极少，不要为了填满而硬塞。

**サ変 vs 動詞 的分界**：能不能单独说「N する」。勉強する（○）→ `verbal-noun`；いらいらする 里的 いらいら 不能单独当名词用 → `verb`。

---

## 4. 自他（`transitivity`）

只对 `pos` 是 `verb` 或 `verbal-noun` 的词写，其他词性一律**不写这个字段**。

| 值 | 判定 | 例子 |
| --- | --- | --- |
| `intransitive` | 「N が <w>」成立、「N を <w>」不成立 | 流れる、落ち着く、発展する |
| `transitive` | 「N を <w>」成立 | 流す、決める、利用する |
| `both` | 两种都成立，且主客体可同可不同 | 開く（ドアが開く／ドアを開く）、増す |

判定的操作办法：拿你脑子里的两个句子去试，**「N が <w>」和「N を <w>」都造得出来且意思不变**才是 `both`。

```
○ ドアが開く      ○ ドアを開く        → both
○ 水が流れる      × 水を流れる        → intransitive
× 電気が消す      ○ 電気を消す        → transitive
```

拿不准（尤其 サ変名詞：影響する、発生する、維持する）就**不写** `transitivity`，写进待确认清单，不要猜。

---

## 4.5 基本形（`lemma`）

库里有一批词条写的不是基本形，判定词性和写骨架都必须以**基本形**为基准：

| 情况 | 现有写法 | 应写 `lemma` |
| --- | --- | --- |
| 动词敬体 | `生きます`、`計算します`、`辞めます` | `生きる`、`計算する`、`辞める` |
| 教材的形容词/名词注释 | `効果的（な）`、`実際（の）` | `効果的`、`実際` |
| 已是基本形 | `流れる`、`効果` | **不写** |
| 完整寒暄 / 短语 | `行ってきます。`、`初めまして。` | **不写**（整句是一个单位，没有基本形） |

- `lemma` 只写基本形本身：不带括号、不带 `～`、不带空格、不带句号，长度 ≤ 12 字符。
- 骨架里的 `<w>` 展开的就是 `lemma`；没有 `lemma` 时就是 `word` 本身。
- 所以：**`word` 是敬体而 `lemma` 没写，骨架一定是错的。** 这是硬性约束。

## 5. 搭配骨架（`patterns`）

最有价值的一块。要回答的是：**这个词跟哪些助词、哪些固定搭配绑在一起。**

### 5.1 骨架写法

- `<w>` 代表被解释的这个词本身，**每条 pattern 必须含且只含一个 `<w>`**。
  不要用 `～` 当占位符：库里有 172 个词条自己的写法就带 `～`（`～代`、`～社`、`数～`），会撞上。
- `N` 代表名词，`V` 代表动词，`A` 代表形容词。
- 助词照抄日语原形（が・を・に・で・と・から・より），**不写中文解释**。
- 标记之间用**半角空格**分隔：`N に <w>`、`N を <w>する`、`N が <w>ている`、`<w> に N`。
- 长度上限 24 个字符，只写骨架，不写例句。

### 5.2 挑哪些

按价值排序，一篇最多 3 条，最少 0 条：

1. **决定助词的那条**（最优先）：`N に <w>`（いらいらする）、`N を <w>`（流す）、`N が <w>`（ある）。
2. **固定搭配 / 惯用组合**：`N を <w>`（効果を発揮する）、`N が <w>`（効果が出る）。
3. **常见活用形带来的固定说法**：`N が <w>ている`（音楽が流れている）。

已经能从词性推出来的不写：ナ形容詞 写 `N が <w>だ` 是废话；名词写 `N の <w>` 也是废话。**只写这个词特有的、用错了会被人听出问题的那些。**

**这三类一律不写 `patterns`**（写了就是错的，校验会挂）：

| 情况 | 为什么 |
| --- | --- |
| `word` 里带 `～` 的构词成分（`～代`、`～社`、`数～`） | `～` 就是它的本体，没有「搭配助词」这回事，`<w>` 无处安放 |
| `pos` 是 `prefix` / `suffix` / `counter` | 同上，缀词只接在别的成分上 |
| `pos` 是 `expression` 且写法带句号的完整寒暄句（`行ってきます。`） | 整句已经定型，拆骨架没有意义；场合说明写进 `analysis` |

### 5.3 说明（`usage`）

- 中文 20–45 字，只讲**为什么是这个助词 / 什么时候这么说**。
- 不重复意思（`meaning` 已经说了意思），不复述骨架。
- 可以点出反直觉的地方：「起点用 から 不用 に」「对象是人时用 に 不用 を」。
- 需要举日语例子时用「」括起来，**英文译文里必须原样出现同一串日文**（校验器会查，见第 10 节）。带 `<w>` 或空格的骨架不要加「」，校验匹配不到。

## 6. 近义辨析（`contrasts`）

回答的是：**这个词和哪个词最容易被搞混，区别在哪。**

### 6.1 选谁

- 必须是**真实存在、学习者真的会混**的词，不是同范畴凑数。
- 优先：同汉字不同词尾（効果／結果／成果、流れる／流す）、同自他组、同中文译词的日语义项分裂（「学习」对应 勉強／学ぶ／習う）。
- 一个词最多 2 项，**1 项是常态，凑不出就不要写**。
- 不写：反义词（大きい↔小さい 不是辨析）、上下位词（犬↔動物）。

### 6.2 怎么写差别（`difference`）

- 中文 25–60 字，必须给出**可操作的选择依据**，三选一至少占一个：
  - **搭配**：が／を／に 不一样
  - **场景 / 语体**：书面 vs 口语、正式 vs 日常
  - **语义侧重**：一个讲过程，一个讲结果
- 只写「语感不同」「意思相近但用法不同」= 无效，等于没写。
- 允许用 `○` / `×` 标可用性：`試験の結果（○）／試験の効果（×）`。
- 有 `wordId`（库里另有一个词条就是它）时才写这个字段，否则只写 `word` 字符串。**不确定 id 就不要写**，不要猜。

### 6.3 对方词的词义（`glossId`）

辨析卡片上要显示成「**流す**（他动词·流走；冲走）：同一件事…」，所以对方词必须带一句词义。规则：

1. 对方词**就在本课词表里** → `glossId` 直接复用它的 `meaningId`，不许另写一份。同一课里同一个词出现两种词义写法是硬伤。
2. 对方词**不在本课**（跨课、跨书，或者只是常识里的词）→ 新建译文 `<本词条 id>.contrast.<序号>.gloss`，写 4–12 个字的简短词义，**只写意思，不写用法**（用法在 `difference` 里）。
3. 两种情况都必须保证该 id 在本课译文里能查到；跨课直接引用别人的 `meaningId` 会取不到译文，运行时整份拒收。
4. 词义要和本词的 `meaning` 保持同一套用词习惯（「流淌」不要这里写「流动」），否则读者会以为两个词意思不同。

```json
"contrasts": [
  {"word": "流す", "glossId": "…1.word.3.contrast.0.gloss", "differenceId": "…1.word.3.contrast.0.difference"},
  {"word": "落ち込む", "wordId": "chukyu-o-manabo-chukyu-zenki.1.word.7", "glossId": "chukyu-o-manabo-chukyu-zenki.1.word.7.meaning", "differenceId": "…"}
]
```

## 7. 兜底拆解（`analysis`）

还是保留 `analysisId` 那一格，但**只在上面三块装不下时**才用：

- 构词：わたし＋たち、お＋名詞
- 汉字 / 读音的坑：促音便、熟字训
- 语体限制：男性用语、儿童用语、只能用于否定
- 词源 / 惯用来源，能帮记忆的

规则：中文 40–90 字，一段话，不分行；不重复 patterns / contrasts 已经说过的内容。没有可写的就**不写**。

## 9. 反例

| 坏输出 | 问题 |
| --- | --- |
| 「这个词是自动词，表示流动的意思，常常用来描述水的运动。」 | 没助词、没骨架，等于把意思说了第二遍 |
| `pattern: "水が流れる"` | 骨架里塞了具体名词，换词就废；应该写 `N が <w>` |
| 「流れる 和 流す 意思相近但用法不同。」 | 无信息量，违反 6.2 |
| `contrasts: [{word: "進行"}]`（因为都跟「进展」有关） | 不构成混淆，凑数 |
| `contrasts: [{word: "結果", differenceId: "…"}]`，漏了 `glossId` | 卡片上会只剩一个光秃秃的「結果」，读者不知道它是什么意思；该项必须同时带词义 |
| `{"word": "生きます", "patterns": [{"pattern": "N が <w>", …}]}`，没写 `lemma` | `<w>` 会展开成「生きます」，骨架变成病句；敬体词条必须补基本形 `生きる` |
| 给 `～代`、`～社` 写 `patterns` | 它本身就是接续成分，`<w>` 无处安放 |
| 在 `patterns` 里写 `N を 流す`，因为「流す 是它的他动词」 | 那是 `contrasts` 的内容，串块了 |
| `pos: "adjective"` | 不在枚举里，校验直接挂 |
| 名词也写 `transitivity` | 只有动词才写，校验直接挂 |

## 10. 硬约束（逐条自查）

1. 不改 `id` / `word` / `reading` / `meaning`；不新增、不删除词条；不调整顺序。
2. `pos` 只能取第 3 节的 13 个值之一，**每个词必填**。
3. `transitivity` 只出现在 `verb` / `verbal-noun` 上。
4. 每条 pattern 恰好一个 `<w>`，长度 ≤ 24 字符；说明 20–45 字。
5. `word` 不是基本形时必须写 `lemma`（敬体、带括号注释的都算）；`lemma` 不含括号、`～`、空格、句号。
6. 带 `～` 的构词成分、`prefix` / `suffix` / `counter`、带句号的完整寒暄句：**不写 `patterns`**。
7. contrasts 每项必须同时有 `word`、`glossId`、`differenceId`；`word` 不得等于本词；`difference` 必须含搭配 / 场景语体 / 语义侧重中至少一种依据；`gloss` 4–12 字，只写意思不写用法。
8. 中文里用「」引的日文，**英文里必须一字不差地出现**（仓库校验 `content:translation` 会逐条查）。纯中文词义的「」不在这条约束内，但同样建议两边对应。
9. 英文不是机翻中文：同一套信息，用英文重写一遍，不是逐字对应。
10. 没有的字段整个不写；不写 `null`、不写 `""`、不写占位语（「暂无」「待补充」「—」）。
11. 不确定的一律留空 + 进清单，**不许猜**。猜错一条，学习者会错一年。
12. `pos` / `transitivity` 只写枚举值，`pattern` / `contrasts[].word` / `lemma` 只写日语原文。**任何中文或英文说明都必须落进 `texts` 的 `zh` / `en`**，不许内联在字段里（见 11.1）。
13. 输出只有 JSON 文件和一份清单，不要夹解释文字、不要 Markdown 代码块以外的内容。

## 11. 与类型定义的对应

`Word` 的相关字段（完整定义见 `content-model.md` §5.4）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `pos` | `PartOfSpeech` | 封闭枚举，每个词必填 |
| `transitivity` | `Transitivity` | 只对 `verb` / `verbal-noun` 写 |
| `lemma` | `string` | 基本形，只在写法不是基本形时写 |
| `patterns` | `WordPattern[]` | `pattern`（日语原形）+ `usageId` |
| `contrasts` | `WordContrast[]` | `word` / `glossId` / `wordId?` / `differenceId` |

### 11.1 三类字段，三种国际化方式（不要混）

| 字段 | 存什么 | 怎么国际化 | 为什么 |
| --- | --- | --- | --- |
| `usageId` / `glossId` / `differenceId` / `analysisId` | 译文 id，本身不含文字 | 一条译文一份 zh/en | 每个词的说法都不同，必须逐条翻译 |
| `pos` / `transitivity` | 枚举值，不是文本 | **界面文案** `ui.partOfSpeech.*` / `ui.transitivity.*`，全局一份 | 全库词条共用同一个「自动词」，按词条存译文等于把同一句话重复上千遍 |
| `pattern` / `contrasts[].word` / `wordId` / `lemma` | 日语原文、词条 id | 不翻译 | 学习对象语言的原文，翻了就不再是这个语言 |

所以「解析要支持国际化」在实现上是两件事：**讲解文本 100% 走译文 id**（不在 `pos` / `pattern` / `word` 里写任何中文或英文说明）；**枚举的显示文案走 `ui.*`**，一次定好、随界面语言切换，不在数据里按词条存。

界面文案的 key 与 `UiTextId` 联合类型必须同改（`data/content/localization/ui.json` 与 `src/modules/localization/domain/ui-text-ids.ts`）。枚举取值是 kebab-case、界面 key 是 camelCase（`i-adjective` → `iAdjective`）；映射写成 `Record<PartOfSpeech, UiTextId>`，漏一个由类型检查拦住。

骨架里的图例（`N` / `<w>` 各代表什么）也只存一条界面文案 `ui.wordPatternLegend`（zh「N＝名词，加粗处为本词」），不按词条存；界面上 `<w>` 换成这个词的基本形并加粗显示。

## 12. 执行流程

1. 一批 = 一本书的一课；把该课词条按第 1 节整理成输入。
2. 先通读全批，列出**近义组**（同一组里的词互相做 contrast，别每组都挑同一个词）。
3. 逐词判定 `pos` / `transitivity`，再挑 patterns，最后才写 contrasts。
4. 写完自查第 10 节 13 条。
5. 输出 `logs/word-analysis/<课 id>.json` + 汇报（不放 `data/`，由合并脚本带断言写回）。
6. 汇报格式：

```text
课 id：chukyu-o-manabo-chukyu-zenki.1
词数：24（名词 11 / サ変 3 / 动词 8 / ナ形 2）
pos 覆盖：24/24
transitivity：8/8 动词，其中 both 1
patterns：合计 31 条，0 条的词 3 个（理由：纯名词，无固定搭配）
contrasts：9 条，涉及 6 组近义
待确认：3 条（維持する 自他未定 / 効果 是否与 成果 区分 / リラックスする 词性）
```

## 13. 一致性

跨批最容易走形的是**同一组近义词在不同课里被讲成不同的区别**。所以：

- 开工前先读已有内容：`node -e` 或直接看 `data/content/localization/learning.json` 里已有的 `*.word.*.note` / `*.analysis` 译文，沿用同一套说法和用词（「他动词」「サ変名詞」「起点」这类术语不要换同义词）。
- 同一组词（流れる／流す、効果／結果／成果）在**先出现的那一课里讲透**，后面出现的词只写一句反向引用，不重讲一遍。
- 拿不准就查 `docs/content-model.md` 与既有译文，不要看心情换说法。
